Environment: macOS (arm64), Node 24.18.0, pnpm 10.18.0, Chrome for Testing
(`chromium-1243`, Chrome 157), Safari not yet tested.

E2E notes:

- Branded Chrome 157 ignores `--load-extension`; the script uses a Playwright-managed
  **Chrome for Testing** binary and falls back to `CHROME_PATH`.
- The E2E build (`dist/e2e`) adds `<all_urls>` **only for the test**, because `activeTab` is
  granted by a real toolbar click, which Playwright cannot perform. The shipped build
  (`dist/chrome`) keeps zero host permissions and is what the packaging script reads.

## Known gaps at this snapshot

- Real toolbar capture (activeTab) and the OS protocol dialog are still manual checks.
- No Safari run yet.
- Readable extraction now uses Readability; Defuddle comparison (V-04) is still pending.
- CSS background images and webfonts are not inlined; cross-origin stylesheets are skipped (CORS).
- Local saves are single files; embedded images are only carried in the handoff package.
