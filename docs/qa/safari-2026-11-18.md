# Safari container build — evidence (2026-11-18)

Environment: macOS, Xcode 27.2 (Build 27B52), `safari-web-extension-converter` from
`/Applications/Xcode.app/Contents/Developer/usr/bin`.

## Generated project

```text
apps/safari/Graphock Web Clipper/
├── Graphock Web Clipper.xcodeproj        (project.xcproj)
├── Graphock Web Clipper/                 container app (Swift, AppDelegate, ViewController)
└── Graphock Web Clipper Extension/       Safari web extension target
```

- App bundle id: `com.moewolf.graphock.webclip`
- Extension bundle id: `com.moewolf.graphock.webclip.Extension`
- Regenerate: `node tooling/build/safari-project.mjs` (idempotent)

## Safari-specific build differences

| Item | Chrome | Safari |
| --- | --- | --- |
| `downloads` permission | yes | **removed** (API unavailable) |
| `offscreen` permission | yes | **removed** (API unavailable) |
| background | ESM service worker | **classic IIFE** bundle (Safari MV3 does not support `type: module`) |
| `minimum_chrome_version` | 120 | removed |
| `options_ui.open_in_tab` | yes | removed (unsupported key) |
| Local save | downloads API + offscreen Blob | extension page (`save.html`) + `<a download>` |
| File handoff channel | yes (Direct) | disabled (no absolute download path) |

The converter produced no unsupported-key warnings after these changes.

## Commands and result

```bash
pnpm safari:project
xcodebuild -project "apps/safari/Graphock Web Clipper/Graphock Web Clipper.xcodeproj" \
  -scheme "Graphock Web Clipper" -configuration Debug -destination 'platform=macOS' \
  CODE_SIGNING_ALLOWED=NO build
# → ** BUILD SUCCEEDED ** (ad-hoc signing, hardened runtime disabled)
```
