# Code of Conduct

This project follows the [Contributor Covenant](https://www.contributor-covenant.org/), version
2.1.

In short:

- Be respectful. Disagree about code, not people.
- No harassment, discrimination, doxxing or personal attacks.
- Assume good faith; ask before escalating.
- Maintainers may remove comments, commits or contributions that violate these rules.

Enforcement: report to **conduct@graphock.com**. Reports are handled confidentially.
